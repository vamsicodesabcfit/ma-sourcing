# Screenshot assets (optional)

Add PNG screenshots here so the in-app **Documentation** tab can display them.

Suggested filenames (match `streamlit_app.py`):

| File | Suggested capture |
|------|---------------------|
| `discover-tab.png` | Discover tab: strategy brief + prompt panel + paste JSON |
| `enrich-tab.png` | Enrich tab: source selection + enrichment prompt + master table |
| `workflow-tab.png` | Workflow tab: data editor + session backup |
| `export-tab.png` | Export tab: download buttons |

Use **1280–1600px** width for readability. If a file is missing, the Documentation tab skips it and shows the written guide only.
